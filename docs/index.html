Tudo o que uma sessão de música precisa

Busca por nome ou link
Digite o que quer ouvir ou cole um link. Playlists inteiras entram na fila de uma vez.
Fila que você controla
Veja a fila, embaralhe, mova, troque ou remova faixas pelo número. /playtop fura a fila quando a música não pode esperar.
Reprodução sob medida
Pause, retome, pule, ajuste o volume de 0 a 200 e escolha o modo de repetição: faixa, fila ou autoplay.
Moderação no mesmo bot
/ban e /purge só aparecem para quem tem permissão no servidor, e o bot confere de novo antes de agir.

Comandos

Tocar

  • /playToca uma música ou playlist
  • /playtopToca antes da próxima da fila
  • /pausePausa a faixa atual
  • /resumeRetoma a reprodução
  • /skipPula a faixa atual
  • /stopPara tudo e limpa a fila
  • /volumeVolume de 0 a 200
  • /repeatOff, faixa, fila ou autoplay

Fila

  • /queueMostra a fila
  • /playingFaixa atual com barra de progresso
  • /shuffleEmbaralha a fila
  • /moveMove uma faixa para outra posição
  • /swapTroca duas faixas de lugar
  • /removeRemove uma faixa pelo número

Servidor

  • /helpLista os comandos disponíveis
  • /getuserNome, ID e avatar de um usuário
  • /banBane um membro (exige Banir Membros)
  • /purgeApaga de 2 a 100 mensagens (exige Gerenciar Mensagens)

Hospede o seu MiMusic

  1. Crie uma aplicação no Discord Developer Portal, adicione um bot e copie o token. 
    git clone https://github.com/clcmo/Mi_Music.git
cd Mi_Music
cp .env.example .env   # cole o token em DISCORD_TOKEN
  2. Suba o bot com Docker ou direto com Node 18+. 
    docker compose up -d --build
# ou
npm ci && npm start
  3. Convide o bot para o servidor com os escopos bot e applications.commands e as permissões Ver Canal, Enviar Mensagens, Inserir Links, Conectar e Falar.
  4. No servidor, o dono do bot envia !deploy uma vez para registrar os comandos de barra.
